# react-native-ino-player

 A full-featured media(audio/video) player for React Native ecosystem

## Installation


```sh
npm install react-native-ino-player
```


## Usage


```js
import { multiply } from 'react-native-ino-player';

// ...

const result = multiply(3, 7);
```
